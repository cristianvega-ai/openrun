# The integration tests that cannot apply to a login shell, for `script/ci_shell_matrix`.
#
# The suite runs under zsh, bash 3.2 (bash3, the bash that macOS ships), Homebrew's bash (bash5),
# fish and PowerShell 7 (pwsh). Every test runs in every shell except the ones listed here, and a
# test that is listed is left out of that shell's run (a filter, not a skip) and checked instead:
# in the "excluded" run each one must skip itself (OPENRUN_EXPECT_SKIP=1), so an entry whose
# test could run now fails CI. Each test still carries its own check of the shell
# (`set_should_run_test`), so a test that runs in a shell it does not fit is a failure in CI
# (CI=true), not a pass.
#
# A group is `[shells] reason`, followed by the full names of its tests (see `cargo nextest list`).
# A reason says why the scenario does not exist in that shell. A product gap is not hidden here:
# its reason says so, and the gap is tracked outside this file.
